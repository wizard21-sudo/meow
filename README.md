# XIAI-MAO (Desktop Cat Pet) 

An interactive desktop pet built with Godot engine!

## Features :
- **Taskbar Docking**: Rests cleanly right above your Windows taskbar.
- **Interactive Speech**: The cat always meows to you.
- **Link Opening**: Right-click opens a custom web link.
- **Drag & Drop**: Click and hold to move the cat anywhere across your screen.
